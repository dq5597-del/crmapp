# 產品清單（排序）檢視表

在「產品匯入」試算表新增一張工作表，命名為 **產品清單（排序）**，
在 **A1** 貼上下列公式（整條，只貼這一格）：

```
={產品匯入!A1:AF1;
  SORT(
    FILTER(產品匯入!A3:AF,
      INDEX(產品匯入!A3:AF, 0, MATCH("產品名稱", 產品匯入!A1:AF1, 0))<>""),
    MATCH("品牌", 產品匯入!A1:AF1, 0), TRUE,
    MATCH("型號", 產品匯入!A1:AF1, 0), TRUE)}
```

## 這條公式做了什麼

| 片段 | 作用 |
|------|------|
| `{產品匯入!A1:AF1; ...}` | 第一列沿用原表表頭 |
| `FILTER(... <>"")` | 濾掉沒有產品名稱的空白列 |
| `SORT(..., MATCH("品牌"...), TRUE, MATCH("型號"...), TRUE)` | 品牌 A→Z，同品牌內型號 A→Z |
| `MATCH(...)` | 用欄位名稱找欄，日後欄位順序調動不必改公式 |

## 欄位範圍說明

`A:AF` = 前 32 欄，即產品資料欄（對應 `product-sync.gs` 的
`GH_PRODUCT_COLUMN_COUNT = 32`）。

同步系統欄（CRM產品ID / CRM更新時間 / 同步狀態 / 最後同步時間 / 同步訊息）
在第 33–37 欄，檢視表刻意不顯示。若要一併顯示，把公式裡所有
`AF` 改成 `AK`。

## 注意事項

- **這張表是唯讀檢視**，公式產生的儲存格不能直接編輯。
  要改資料請回「產品匯入」工作表。
- 原表完全不受影響，同步邏輯照常運作，不會觸發 `onEdit`。
- 資料一有變動，這張表自動重排，不需手動操作。
- **中文品牌不保證筆畫順序**——`SORT()` 使用 Google 的排序規則。
  若需要嚴格的筆畫序（少→多），改用 `product-sort.gs` 的
  「光輝系統 → 依品牌排序」選單。
